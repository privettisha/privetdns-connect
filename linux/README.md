# Arch Linux x64

Требуются NetworkManager, systemd-resolved, systemd, `nmcli`, `resolvectl`, `ip`, `xdg-open` и Python 3. Никаких пакетов через pip не требуется.

1. Создайте устройство **Linux** в [кабинете PrivetDNS](https://privetdns.ru/cabinet) и скопируйте личное имя DoT вида `…dot.privetdns.ru`.
2. Распакуйте `PrivetDNS-Connect-Arch-x64.zip`.
3. В терминале выполните `sudo ./PrivetDNS-Connect`.
4. Приложение откроет локальную страницу. Если браузер не открылся, скопируйте адрес из терминала. Вставьте имя DoT и нажмите «Подключить».

После подключения терминал можно закрыть: DNS-служба работает через systemd. Для отключения снова запустите приложение и нажмите «Отключить и восстановить DNS».

Только домены из встроенного списка идут через персональный DoT; остальные используют исходные DNS-серверы сети. Установщик сохраняет прежние настройки и включает таймер автоматического возврата до переключения DNS. При аварийном прерывании восстановление можно запустить вручную: `sudo python3 /var/lib/privetdns-native/recovery.py recover`.

Первый выпуск рассчитан на обычный Arch с NetworkManager и работающим systemd-resolved. Если установлен сторонний DNS-конфиг, другой VPN или нестандартный `/etc/resolv.conf`, приложение остановится до изменений и покажет причину.
