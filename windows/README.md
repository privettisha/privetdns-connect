# Windows 10/11 x64

Запустите `PrivetDNS-Connect-Windows-x64.exe` от имени администратора. Вставьте личную DoH-ссылку Windows-устройства из кабинета и нажмите «Подключить». Для отключения запустите тот же файл и нажмите «Отключить и восстановить DNS».

Требуется Windows 10 версии 2004 или новее либо Windows 11. Установщик не меняет DNS-адреса адаптеров. Он запускает локальную службу и задаёт правила NRPT только для поддерживаемых доменов. Если служба или проверка DNS не запустятся, установка отменяется.

Клиент не перехватывает собственный DoH браузера и не заменяет VPN. Установка может быть отклонена при корпоративной DNS-политике или конфликте с другой установкой PrivetDNS.

Это проверочный выпуск. Сборка под Windows выполнена, но полевые испытания на чистых Windows 10 и 11 ещё нужны.
