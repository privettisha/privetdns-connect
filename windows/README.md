# Windows 10/11 x64

1. Скачайте `PrivetDNS-Connect-Windows-x64.exe`.
2. Запустите файл и разрешите установку.
3. Вставьте личную DoH-ссылку Windows-устройства из [кабинета PrivetDNS](https://privetdns.ru/cabinet).
4. Нажмите «Подключить».

Для отключения запустите тот же файл и нажмите «Отключить и восстановить DNS».

Поддерживаются Windows 10 версии 2004 и новее, а также Windows 11. Python и PowerShell устанавливать не нужно.
