# PrivetDNS Connect

Приложение PrivetDNS для Windows 10/11 и Arch Linux. Подключает персональный Smart DNS только для поддерживаемых доменов — остальные сайты продолжают использовать обычный DNS вашей сети.

## Скачать

Откройте [релиз v0.1.0](https://github.com/privettisha/privetdns-connect/releases/tag/v0.1.0) и скачайте файл для своей системы:

- **Windows 10/11:** `PrivetDNS-Connect-Windows-x64.exe`
- **Arch Linux:** `PrivetDNS-Connect-Arch-x64.zip`

## Windows 10/11

1. Запустите EXE-файл и разрешите установку.
2. Создайте Windows-устройство в [личном кабинете](https://privetdns.ru/cabinet).
3. Скопируйте личную DoH-ссылку, вставьте её в приложение и нажмите «Подключить».

Для отключения снова запустите приложение и нажмите «Отключить и восстановить DNS». Python и PowerShell не нужны.

## Arch Linux

1. Создайте Linux-устройство в [личном кабинете](https://privetdns.ru/cabinet).
2. Скопируйте личное имя DoT.
3. Распакуйте архив и запустите `sudo ./PrivetDNS-Connect`.
4. Вставьте имя DoT на открывшейся странице и нажмите «Подключить».

Для отключения снова запустите приложение и выберите восстановление DNS.

Личная DoH-ссылка или имя DoT относятся только к вашему устройству. Не публикуйте их и не отправляйте посторонним.

Подробные инструкции: [Windows](windows/README.md) · [Arch Linux](linux/README.md).

## Сборка

Установите Go 1.26+ и Python 3, затем выполните `bash build.sh`. Готовые файлы появятся в папке `dist/`.
