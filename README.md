# PrivetDNS Connect

Простое приложение для персонального Smart DNS. Windows 10/11 использует личную DoH-ссылку, Arch Linux — личное имя DoT. Их можно скопировать в карточке устройства на [privetdns.ru](https://privetdns.ru/cabinet).

Только домены из списка `smartdns-domains.txt` направляются к PrivetDNS. Остальные домены используют DNS текущей сети. Это не VPN и не туннель для всего трафика.

## Скачать

Откройте [проверочный выпуск v0.1.0](https://github.com/privettisha/privetdns-connect/releases/tag/v0.1.0):

- Windows 10/11 x64: `PrivetDNS-Connect-Windows-x64.exe`. Запустите, разрешите UAC, вставьте личную **DoH-ссылку** и нажмите «Подключить». Python и PowerShell не нужны. Тот же EXE отключает PrivetDNS.
- Arch Linux x64: `PrivetDNS-Connect-Arch-x64.zip`. Распакуйте и выполните `sudo ./PrivetDNS-Connect`. В открывшемся окне браузера вставьте личное **имя DoT** и нажмите «Подключить». Arch использует встроенный в систему Python 3 для системной настройки; ничего через pip не устанавливается.

До установки закройте другой VPN и убедитесь, что у вас есть обычный интернет. Если браузер использует собственный Secure DNS, настройка системного DNS может на него не влиять.

## Что происходит на компьютере

Windows создаёт локальную DNS-службу и правила Windows NRPT только для поддерживаемых доменов. DNS-адреса Wi-Fi, Ethernet и IPv6 не переписываются. При неудачной проверке установка отменяется.

Arch сохраняет исходные настройки NetworkManager и systemd-resolved, запускает локальную DNS-службу, проверяет обычные сайты и выбранный Smart DNS, затем применяет конфигурацию. Если установка прервана, срабатывает автоматический откат. При сбое службы используйте кнопку восстановления в приложении либо `sudo python3 /var/lib/privetdns-native/recovery.py remove`.

Персональная ссылка или имя — секрет устройства. Они не записываются в репозиторий и не должны попадать на скриншоты.

## Совместимость и статус

Это первый публичный выпуск для проверки владельцем. Исходный код и сборки проверяются автоматически, но успешная установка на разных реальных Windows 10/11 и Arch пока не подтверждена. Результат может зависеть от корпоративных DNS-политик, другого VPN, антивируса и сетевых настроек. Если проверка не проходит, приложение сообщает причину и возвращает прежние настройки.

Подробности: [Windows](windows/README.md) · [Arch Linux](linux/README.md).

## Сборка из исходников

Нужны Go 1.26+ и Python 3 на машине сборки. Запустите `bash build.sh`. Скрипт создаст файлы в `dist/`. Windows EXE собирается из Go-кода без Python в клиентской системе.

Код распространяется по лицензии [MIT](LICENSE). Компонент `golang.org/x/sys` имеет отдельную лицензию; сторонний код не встраивается в репозиторий.
